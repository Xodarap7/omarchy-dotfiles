# Защита приватного диска HDD_BLUE

1. Каталог `/mnt/hdd_blue` является строго приватным хранилищем пользователя.
2. Агентам КАТЕГОРИЧЕСКИ ЗАПРЕЩЕНО:
   - Переходить в каталог `/mnt/hdd_blue`.
   - Просматривать, перечислять файлы (`ls`, `find`, `dir`), читать содержимое любых файлов на `/mnt/hdd_blue`.
   - Производить поиск, индексацию или любые операции с данным разделом.
3. Раздел аппаратно изолирован через Linux Mount Namespace (Bubblewrap) и не подлежит вмешательству.
